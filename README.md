# public-directory-for-bd

A modern, curated public directory and emergency contacts portal for Bangladesh.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS & Lucide Icons
- **Language:** TypeScript

## Getting Started

First, run the development server:

```bash
pnpm dev
# or
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
